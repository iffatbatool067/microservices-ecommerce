Core Modules

Microservices

The platform is divided into four main services to keep the system clean, scalable, and easy to deploy.

User Service

Manages user registration, login, profiles, and authentication.

Product Service

Handles product catalog, product details, and inventory information.

Order Service

Processes customer orders and manages order status.

Notification Service

Sends order confirmations, alerts, and system notifications.

Project Overview

CloudMart represents a cloud-native e-commerce system designed using DevOps practices. The website is containerized with Docker and deployed through an automated CI/CD workflow.

The main goal is to demonstrate service-based architecture, environment separation, and automated deployment.

  • Docker based containerization
  • Kubernetes deployment support
  • Jenkins CI/CD pipeline
  • Development, staging, and production environments
